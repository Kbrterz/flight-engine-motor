How it works

Two layers, kept strictly apart

Deterministic engine

Computes every number

Results come from a versioned, auditable engineering rule set. Same input, same output. No AI anywhere on this path.

Guarded AI layer

Explains, never decides

Plain-language explanation of the result. It never recalculates or changes a value. Unverifiable explanations are blocked — the user then sees the deterministic result alone.

Inputs Deterministic engine Result Guarded AI Verify vs. result Explanation / blocked

The result is produced before AI is called. AI failure never blocks the number.

AI assists the reader. It never touches the decision.
